# Python 10-in-1 Game Collection 🎮

It is a modular collection of 10 interactive command-line games built with Python! This project demonstrates modular programming, file handling, and Python logic implementation by organizing multiple distinct game scripts into a single, cohesive package controlled by a central menu system.

## 📂 Project Structure

Unlike simple script dumps, this project is organized as a Python package:

```text
Python-10-in-1-Game-Collection/
├── games/                  # Package containing all game modules
│   ├── __init__.py         
│   ├── blackjack.py
│   ├── pet.py
│   └── ... (8 other games)
├── main.py                 # Central entry point
├── Report/
│   └── Report_file_ananya-joshi.pdf
└── README.md
```

## 🕹️ Included Games

1. **Blackjack**: A classic card game against a computerized dealer.
2. **Dice Rolling Simulator**: Simulates rolling various types of dice with different faces.
3. **Mad Libs Generator**: A word game where you fill in the blanks to create a funny story.
4. **Magic 8-Ball**: Ask a question and receive a fortune.
5. **Password Generator**: Generates secure passwords based on user preferences.
6. **Pet**: A virtual pet game where you feed and play with your pet.
7. **Quiz**: A fun compatibility or trivia challenge.
8. **Random Number Guesser**: Try to guess the number the computer is thinking of.
9. **Rock Paper Scissors**: The classic hand game against the CPU.
10. **Word Scramble**: Unscramble the jumbled words before time runs out.

## 🚀 How to Run

You do not need to run individual files. The `main.py` file acts as a central hub.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ananyajoshi-cseai/Python-10-in-1-Game-Collection.git](https://github.com/ananyajoshi-cseai/Python-10-in-1-Game-Collection.git)
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Python-10-in-1-Game-Collection
   ```

3. **Run the main program:**
   ```bash
   python main.py
   ```

## 🛠️ Requirements

* Python 3.x
* No external libraries required (uses standard Python libraries like `random`, `os`, `sys`, `time`).
