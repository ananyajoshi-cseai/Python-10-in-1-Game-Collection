# Python 10-in-1 Game Collection

## 📌 Introduction

This project is a console-based application that bundles ten different mini-games and utilities into a single, cohesive, menu-driven program. It was developed to demonstrate foundational Python programming concepts including control flow, data structures, and modular design.

**Author:** Ananya Joshi
**Course:** Programming With Python (CSE AI)

## 🎮 Features

The collection includes the following 10 programs:

1. **FLAMES Compatibility Calculator:** Calculates the relationship between two names using the classic FLAMES algorithm.
2. **Guessing Number Game:** A game where the user guesses a random number generated by the system within a specified range.
3. **Rock Paper Scissors:** A classic game played against the computer.
4. **Blackjack (Simplified):** A card game where the goal is to get a hand value closer to 21 than the dealer without going over.
5. **Password Generator:** A utility that generates secure random passwords containing uppercase, lowercase, digits, and special characters.
6. **Magic 8-Ball:** A fun simulation that provides random answers to yes/no questions.
7. **Word Scramble:** A skill game where the user must unscramble jumbled letters to form a valid word.
8. **Mad Libs:** A word game where the user provides various words (nouns, verbs, adjectives) to create a humorous story.
9. **Dice Rolling Simulator:** Simulates rolling one or more dice with a user-specified number of sides.
10. **Pet Simulator:** A text-based state management game where you care for a digital pet by managing its hunger, happiness, and energy.

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.x
* **Libraries:** Uses only Python Standard Libraries (`random`, `time`, `sys`, `os`), so no external installation is required.
* **Platform:** Works on Windows, macOS, and Linux.

## 🚀 How to Run

1. Ensure you have Python installed on your system.
2. Clone this repository or download the source code.
3. Open your terminal or command prompt.
4. Run the script:
`python main.py`
5. Enter a number (1-10) from the main menu to launch a specific program.
