# Python-10-in-1-Game-Collection
Modular, console-based Python application combining ten mini-games and utilities in a menu-driven interface. Built by Ananya Joshi. Includes Blackjack, Rock Paper Scissors, Number Guessing, Pet Simulator, Dice Roller, Magic 8-Ball, FLAMES, Mad Libs, Word Scramble, and a Secure Password Generator. Built using only the Python Standard Library.
